# 术语与文献整理

## 专业术语（按 A-Z 排序）

### A

- Abundance Culture 丰裕文化：不以稀缺和积累为核心前提的文化形态
- Acculturation 文化习得机制：个体学习自身社群文化的过程
- Accounting Rules 会计规则：此处指美国 GAAP（一般公认会计原则）
- Adverse Possession 逆权占有：公开、持续、排他占有弃置土地取得产权

### B

- Benevolent Dictator (BDFL) 仁慈独裁者：项目产权归其所有的领导者
- Big Iron 大铁块：传统大型主机
- Blinkenlights 闪烁指示灯：上古计算机文化符号
- Brooks' Law 布鲁克斯定律：增加人力只会让延期项目更延期
- Bundle of Rights 权利束：产权不是"物"本身而是权利配置

### C

- Calculation Problem 计算问题：奥地利经济学派核心概念（米塞斯 1920 / 哈耶克）
- Category Killer 品类杀手：占据整个生态位的成功项目
- Chain of Title 产权链：产权从最初垦殖者到当前持有者的连续转让记录
- Cherrypicking 摘樱桃：双关：拣轻松工作 + git cherry-pick
- Clarke's Third Law 克拉克第三定律：足够先进的技术与魔法无异
- Co-maintainer / Co-developer 共同维护者：与 owner 并列
- Collective Intelligence 集体智慧：群体智慧研究谱系
- Common Pool Resources 公共池塘资源：竞争+非排他（哈丁公地即此）
- Congested Public Goods 拥挤性公共物品：消费上具有竞争性但无法有效排他
- Consensus Theory 一致性理论：制度正当性源于集体同意
- Constant Dollars 不变美元：剔除价格波动后的计量单位
- Conway's Law 康威定律：系统架构反映组织沟通结构
- Critical Mass 临界质量：物理学类比
- Cultural Matrix 文化母体：孕育并塑造个体的文化系统
- Cybernetics 控制论：用机器、有机体类比文化与社会

### D

- De-commoditizing 去商品化：微软"拥抱并扩展"策略
- Delphi Effect 德尔菲效应：群体独立判断优于个体判断
- Design-by-committee 委员会设计：集体决策模式

### E

- Egoless Programming 无我编程：温伯格《程序开发心理学》
- Egotism 自我主义：区别于自我中心（egocentrism）
- Ephemeralization 简效化：富勒“少费多用”概念
- Ergosphere 能层/劳作域：旋转黑洞外部能量提取区域，法雷·里多的延伸说法
- Express Warranty 明示担保：双方明确约定的担保
- Extreme Programming 极限编程：肯特·贝克提出

### F

- Family Resemblance 家族相似性：维特根斯坦概念
- Flaming 公开抨击：社群制裁手段之一
- Fork 分叉：项目派生独立分支
- Free-rider Behavior 搭便车行为：奥尔森《集体行动的逻辑》核心概念

### G

- Gift Culture 礼物文化：人类学核心概念，以声望、荣誉等非货币回报为核心的社会交换体系
- Goodwill 商誉：可转化为未来收益的无形资产
- Guild 中世纪行会：依靠声望体系运转的技艺社群

### H

- Handicap Theory 累赘原理：扎哈维 1975 年，"诚实信号"理论
- Hierarchy of Values 需求层次理论：马斯洛
- Homesteading 垦殖：在无主土地上定居并劳作

### I

- Implied Warranty 默示担保：法律自动赋予买卖合同的担保义务
- Intangible Goods 无形商品：不具备实物形态的劳动产品
- Intensional Focus Point 内涵性聚焦点：法雷·里多自创表述
- Intermediate Goods 中间产品：国民经济核算概念
- Intraspecies Violence 种内争斗：动物行为学概念
- Inverse Commons 反向公地：开源软件"越用越多"的特性

### K

- King Log 木头王：《伊索寓言·青蛙求王》

### L

- Legacy Code 祖传代码：无人维护的代码
- Lockean Property Model 洛克财产权理论：英美普通法土地产权制度
- Lock-in Effect 锁定效应：W.B.阿瑟提出，切换成本导致路径依赖
- Lord High Fixer 首席修复官：常年排查修复 bug 的负责人

### M

- Manufactured Goods 制成品：与初级产品相对
- Marginal Cost 边际成本：每多生产一单位产品所增加的总成本
- Market Clearing Price 市场均衡价格：供给量等于需求量时的价格
- Merchantable 适销性：UCC 核心概念
- Milieu 场域：涂尔干传统的文化浸润概念（区别于布迪厄的 field）
- Mixing Labour 掺进劳动：洛克财产权理论核心概念
- Myth 迷思：社会学固定用词

### N

- Network Effect 网络效应：产品或服务价值随用户规模扩大而提升
- Nightly Release nightly 版本：每日构建版本
- Noosphere 智域：人类知识/思想的总域（维尔纳茨基、德日进）
- Non-rivalrous Goods 非竞争性商品：可无限复制的信息类商品

### O

- Ontology 本体论：研究“作为存在的存在”
- Orphan Software 孤儿软件：厂商停止服务支持的软件
- Owner 产权人：项目产权的最终归属者

### P

- Peer Repute 同行声望：被他人评价的维度
- Perceived Value 感知价值：载瑟摩尔 1988 年提出
- Performative Act 述行行为：奥斯汀言语行为理论
- Pirate Culture 海盗文化：软件盗版亚文化
- Potlatch 夸富宴：北美西北海岸原住民的竞争性仪式馈赠活动
- Predatory Monopoly 掠夺性垄断：低于成本定价驱逐对手后抬价
- Present Discounted Value (PDV) 折现值：未来一笔钱折合为现值
- Previous Owner 前手：产权流转链条中的上一任持有人
- Property 产权：英美普通法下可分层、可转让的权利束

### R

- Reciprocity 互惠性：莫斯"给予—接受—回报"的奠基性概念
- Rent 垄断收益：依靠排他性技术、特权壁垒获取的超额利润
- Replacement Costs 重置成本：按当前市价重新购建资产的费用
- Reverse-auction Model 反向拍卖机制：项目方定价、开发者竞标的众包模式
- Rivalrous Goods 竞争性商品：一人消费会减少他人消费的商品

### S

- Sale Value 销售价值：强调销售行为的交换价值
- Scarcity Economics 稀缺经济学：以生存物资稀缺为底层假设
- Self-actualization 自我实现：马斯洛需求层次顶端
- Seniority 贡献资历：冲突解决依据
- Sharecropping 分佃制：地主向农民出租土地，收货后地主和农民进行产量分成
- Shunning 社群孤立：社群制裁手段之一
- SNAFU Principle SNAFU 原则：层级组织信息传递被扭曲
- Social Organism Theory 社会有机体论：斯宾塞的理论
- Spaghetti Code 面条代码：混乱难以理解的代码
- Subsystem Owner 子系统产权负责人：承担子系统产权与维护责任
- Sunk Cost 沉没成本：已支付且无法收回的成本
- Syntactic Sugar 语法糖：可选的“噪音”关键词
- System Theory 系统论：用机器、有机体类比文化与社会

### T

- Tension 张力：社会学固定用词
- Territorial Rule 领地归属规则：权威跟随责任
- Tragedy of the Commons 公地悲剧：哈丁 1968 年提出
- Transfer of Title 产权转让：产权获取方式之一
- Turing Completeness 图灵完备性：一个系统能模拟单带图灵机并执行所有可计算任务的能力

### W

- White Elephant 白象工程：维护成本远高于实用价值的工程
