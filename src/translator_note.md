# 译者序

卫剑钒老师的译本是中文世界引入《大教堂与集市》的开路先锋，曾陪伴一代开发者走近并理解开源精神，是中文开源文化演进过程中一个标志性的里程碑。本译本为**独立重译版本**，在翻译过程中并未参考或沿用任何现有中译本文本。译者认为本书引用人类学、社会学乃至文化背景知识概念并不只是因为“有趣”，而是因为**这些理论概念能够支撑本书的论述链条与理论建构**，因此力图在当下开源协作日益成熟、社区治理逐步系统化、开源协作模式也不再只是黑客的玩具的背景下，提供一个更具理论深度与跨学科视野的解读视角。

译者认为，本书的第 3 章、第 4 章只是用比较口语化的说法包裹层层递进的严谨论述，因此本译本在原文理论建构及论证意图集中的多个小节中采用了**显化论证结构、学术化的翻译方式**，正是希望为未来开源生态的理论探索与实践创新，提供较为坚实的基础设施。本译本在这两章对术语选择和注释密度有明确的学术取向，可能偏离ESR（Eric S. Raymond）作为“黑客散文家”的修辞风格，这一选择的风险与收益，留待读者判断。

译者选择这样处理，并不是因为要做学术研究，而是想在当下的中文语境中为开源理念“正本清源”——**重申“开源”二字背后的真实定义与内涵**。在 21 世纪 20 年代的当下，资本逻辑将开源理念降格为“降低研发成本的人力资本池”与“合规性标签”（AI 大模型时代所谓“开源”只是开放了权重，正是这种降格的极致形态）；政治逻辑将它征用为技术主权的地缘政治工具。更隐蔽的是认知层面的不对等：开源社区丰富的自我阐释（礼物文化、集市动力学、黑客伦理）在国内主流学术与政策话语中仍被视为“经验性描述”或“亚文化修辞”，缺乏与主流社会科学乃至更多领域对话的概念硬通货（conceptual currency），仍然被当作黑客小圈子的自娱自乐。

译者认为，开源知识成果本不至于陷入如此境地，那么能不能让 ESR 的论述链条在中文中显形，保证它的概念精度与严谨程度，不让它坍缩为一本单纯的开源理念宣传小册子呢？当经济学家用“公共品困境”解释开源可持续性时，当政治学家用“数字民粹主义”给开源社区打标签时，当国内人文社科学界仍然没有足够重视开源社区及开源理念，部分人文社科学人对开源社区仍停留在德勒兹式的游牧民浪漫想象，或者陷入技术从业者“被剥削/为虎作伥”的道德二元论时，开源实践者往往因缺乏制度化的理论武器而无力反驳。本译本采用的学术化路径，正是试图在被完全收编之前，为开源界将会出现的一套不可化约的理论铠甲提供基础材料——通过经济学、人类学与政治经济学的严格概念化，证明**开源不是现有秩序的例外或附庸，而是一种需要被认真对待的新社会组织范式**。

本书第 3 章与第 4 章的理论价值长期被主流解读所忽视，ESR 在这些章节中不仅描述开源现象，更融合了工程学、经济学、法学与人类学，试图建构一套“开源工程经济学”的新方法论体系。为此，本译本着重梳理书中涉及的经济学、法学、人类学等概念，补充详尽的学术背景与注释，力求呈现其理论骨架。无论你是开发者、研究者，还是对技术与社会的交汇点感到好奇的跨学科读者，只要你对书中提出的思想框架感到好奇，喜爱智识挑战，并享受其中的乐趣，那么这份译本就是为你准备的。译者希望它能为你提供更系统的概念梳理，帮助你更深入地把握原文语境，并领略作者跨学科思想的独特魅力。

最后，如果你的兴趣不止于代码，也关心它与现代律法的关系，那么劳伦斯·莱斯格的《代码2.0》值得一读；如果想看看国内开源社区曾经的样貌，范小青老师的《开源文化在中国》是一本难得的针对国内开源社区的人类学民族志。另外，在 AO3 等平台上尤其活跃的同人圈，虽然领域和代码毫不相干，这些社区的底层逻辑却是与集市模型高度共通的。

在数字时代，大量纸质文字也有了数字化版本，原先无需担心的文本内容遭删减、篡改的问题在如今愈发明显，微信读书平台《秋园》文本被篡改便是一个先例。本译本不愿将原作者及译者的正当权利让渡给此类平台，因此采取以下方法实现文本可溯源、不可篡改：独立域名部署、译本提交历史不可篡改（分布式仓库维护分布式记录）、版本粒度精确到 commit 哈希、源码与产物双层级 PGP/X.509 签名。一本讲开源与 fork 的书，译者也希望用开源的方式做出来，而不是依赖大教堂的中心权威。

此外，向 Rust 社区（也是本网站的排版工具 mdbook 所属的语言社区）的 unofficial 文化（以及 *Rust Atomics and Locks*、 *Learning Rust With Entirely Too Many Linked Lists*、*The Rust Nomicon* 等书）致敬。本站域名 the-cathedral-and-the-bazaar-unofficial.online 中的 unofficial 正来源于此。

本译本由译者一人独立完成，术语校对、笔误、排版等方面很有可能仍有疏漏。一个开放的文本只有在不断的审视和修正中才能趋于完善，我邀请每一位认真的读者共同完善这个文本，在 issue 中提出建议、批评斧正，你提出的每条反馈都会在 GitHub issue 中留下公开记录；其中被采纳的有效反馈，将进入本译本的 git 版本管理系统，成为提交历史的一部分。让我们共同让这份工作更接近它应有的样貌。
